## 切片 1：脚本生命周期和元数据模型完成

### 完成内容

- 在 `magicops-core` 建立领域枚举：`ScriptStatus`（12 种状态）、`ScriptType`（3 种类型）、`RiskLevel`（4 级）、`ApprovalDecision`。
- 在 `magicops-governance` 建立 `ScriptStateMachine`：完整的合法迁移路径定义，拒绝非法迁移，抛出 `IllegalStateTransitionException`。
- 在 `magicops-audit` 建立 `AuditRecord`（值对象）、`AuditEventType`（9 种事件类型）、`AuditService`（内存存储最小实现，关键审计写入失败阻断）。
- 在 `magicops-console` 建立 JPA 实体：`ScriptEntity`、`ScriptDraftEntity`、`ScriptVersionEntity`、`ApprovalEntity`。
- 建立 Spring Data JPA Repository 和 Flyway 迁移脚本 `V1__init_schema.sql`。
- 建立 `ScriptLifecycleService`：脚本创建、草稿编辑、版本固化、提交审批、审批决策。
- 建立最小 REST API `ScriptController`：`POST/GET /api/scripts`，草稿更新、版本创建、提交审批、审批决策。
- 建立 `GlobalExceptionHandler`：处理 404、409（非法迁移）、400（校验失败）、500。
- Console 和 Runtime 的 `@SpringBootApplication` 已配置 `scanBasePackages = "top.cywu.magicops"`。

  - `ScriptLifecycleServiceTest`：4 个集成测试（DRAFT 到 APPROVED 完整路径、拒绝路径、非法迁移异常、审批审计）。
  - `CoreModuleTest`、`ConsoleApplicationTest`、`RuntimeApplicationTest`：3 个基础测试。

### 关闭标准验证

- 脚本可以从 DRAFT 走到 APPROVED：通过（`fullLifecycle_draftToApproved` 测试）。
- 非法状态迁移被拒绝：通过（`illegalTransition_throwsException` 测试 + 状态机 28 个测试）。
- 审批记录可审计：通过（`approvalRecord_isAuditable` 测试，审批决策为关键审计）。

### 技术决策

| 决策 | 选择 | 原因 |
|---|---|---|
| 数据库迁移 | Flyway | Spring Boot 标准，PostgreSQL 生产环境使用 |
| 开发环境迁移 | JPA ddl-auto=update + Flyway disabled | H2 开发无需 Flyway，简化脚手架阶段 |
| 审计存储 | 内存（第一阶段最小实现） | 后续切片接入持久化 |
| 组件扫描 | scanBasePackages = "top.cywu.magicops" | 多模块共享包前缀，需要扫描 audit/governance 等外部包 |

## 切片 2：发布包签名和 Runtime 验签完成

### 完成内容

- 在 `magicops-sign` 建立 `CanonicalJson` 工具：字典序排序、无空白、UTF-8、LF 脚本规范化。
- 建立 `PackageManifest`（含 `ScriptEntry`）和 `PublishPackage` 模型，第一阶段必需字段完整。
- 建立 `SigningService`：SHA-256 hash、SHA256withRSA 签名/验签、发布包完整性验证（签名 + metadata hash + 脚本 content hash）。
- 建立 `KeyProvider`：从环境变量加载 RSA 密钥对，开发环境自动生成临时密钥对。
- 在 `magicops-console` 建立 `PackageBuildService`：从已审批脚本版本构建 canonical 发布包并签名。
- 在 `magicops-console` 建立 `PushService`：REST 推送发布包到 Runtime。
- 在 `magicops-runtime` 建立 `PackageVerificationService`：验证签名、hash、环境、keyId，原子激活，加载审计。
- 在 `magicops-runtime` 建立 `PackageReceiveController`：`POST /api/packages` 接收发布包，`GET /api/packages/active` 查看当前激活包。

### 验证结果

- `mvn test`：48 个测试全部通过。
  - `SigningServiceTest`：8 个测试（签名验签往返、错误密钥拒绝、篡改数据拒绝、canonical 稳定性、hash 一致性、完整发布包验证、hash 不匹配拒绝）。
  - `PackageVerificationServiceTest`：5 个测试（合法包接受、hash 不匹配拒绝、环境不匹配拒绝、未知 keyId 拒绝、加载审计写入）。
  - 前序测试继续通过：状态机 28 个 + 生命周期 4 个 + 基础 4 个。

### 关闭标准验证

- Runtime 接受合法签名包：通过（`acceptsValidSignedPackage`）。
- Runtime 拒绝 hash 不匹配包：通过（`rejectsHashMismatch`）。
- Runtime 拒绝环境不匹配包：通过（`rejectsEnvironmentMismatch`）。
- Runtime 拒绝未知 key ID 包：通过（`rejectsUnknownKeyId`）。
- Runtime 加载审计成功写入：通过（`loadAuditWritten`，关键审计）。

- 建立 `RepairExecutionService`：dry-run 验证 → SQL Guard 写操作约束 → 真实 JDBC 执行 → 回滚意图记录 → 关键审计写入。

- 在 `SqlGuardService` 新增 `validateForRepair`：允许 INSERT/UPDATE（需 WHERE）/DELETE（需 WHERE），拒绝自由 UPDATE/DELETE。
- 在 `DynamicDataSourceManager` 新增 `executeUpdate`：支持 INSERT/UPDATE/DELETE 语句执行。

- `RepairExecutionServiceTest`：8 个测试（dry-run 成功/失败、无 WHERE 拒绝、DROP 拒绝、SELECT 拒绝修复、无 dry-run 拒绝、自由 UPDATE 拒绝、成功执行+审计、审计失败阻断）。

### 关闭标准验证
